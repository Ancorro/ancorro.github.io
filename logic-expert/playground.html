Diagnostic Observations

Fusion Head, Not Routing

The No-Gate Control (same fusion head, no logic operators) beats the linear-head Baseline by 1.4 percentage points in every seed. No routed variant beats the No-Gate Control (see the paper's Table 1).

Fusion α

A learned α starting at 0.01 shrinks to 0.0077 ± 0.0014, so training turns the logic branch down rather than up.

Computing Parity

Peak GPU memory is closely matched (71.7 GB for Routed vs 70.0 GB for Baseline), so the logic pathway adds little memory on top of the 8B backbone.
